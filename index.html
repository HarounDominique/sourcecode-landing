the problem

Enterprise codebases slow AI agents down.

ERR_COLD_START

Agents re-parse on every session

For a large Java or TypeScript monolith, cold context acquisition takes 5–15 seconds per invocation. Multiply by dozens of agent turns per hour — that's your iteration bottleneck, not the model.

ERR_CHANGE_BLINDNESS

Spring DI hides real callers

Callers inject interfaces via @Autowired. Grep returns zero results. The actual blast radius is invisible until prod breaks.

ERR_MANUAL_HOURS

Impact analysis takes hours

Tracing a change through 3,000–8,000 Java files across service layers, DAO boundaries, and HTTP endpoints is a day's work — done manually.

ERR_ONBOARD_DEBT

Monoliths are opaque to new agents

No orientation, no entry points, no architecture map. Every new agent session starts cold against the same codebase it already analyzed yesterday.

ERR_PR_BLIND

PR reviews miss blast radius

Reviewers see diffs, not transitive dependencies. A one-line change to a core service can silently break 11 endpoints and 2 transactional boundaries.

the solution

Two hard problems. One command each.

sourcecode builds a deterministic symbol graph of your Spring repository — locally, statically, no LLM calls — and answers the two questions that matter most before touching production code.

Get started →
  • What breaks if I change X? — sourcecode impact ClassName /repo traverses the reverse dependency graph and returns every HTTP endpoint, transactional boundary, and downstream module in the blast cone
  • What does this codebase do? — sourcecode onboard /repo produces a bounded, AI-ready context bundle: entry points, architecture, key files, confidence, and gaps. Feed directly to Claude or GPT-4
  • Spring DI-aware traversal — understands interface injection patterns. Targets interfaces, not impls. Returns real blast radius where grep returns zero
  • Persistent structural cache — second run is ~9–17× faster. At 0.3s per call, sourcecode becomes constant infrastructure inside agent loops, not an occasional tool
  • Bounded token output — --compact is 2,500–4,000 tokens; --agent is 4,500–5,500. Never blows your context window
  • Confidence-aware — every analysis includes detection quality and gap list. Agents know what they don't know before they act

cache system

The cache is not a performance optimization.
It is what makes sourcecode infrastructure.

At 2.7s per call, you use sourcecode occasionally. At 0.3s, you call it before every edit, before every PR review, before every test run — without batching manually. Sub-second context retrieval changes the cost model for agent workflows.

Two cache layers

  • L1 — core cache: analysis result keyed by (git_sha, analysis_flags). Survives format changes — regenerate --compact or --agent views from the same core without re-scanning.
  • L2 — view cache: rendered output keyed by (core_hash, view_flags). Exact output match — zero recomputation on hit.
  • Invalidation: keyed on git commit SHA. Any commit invalidates the core for that repo. Uncommitted changes are not cached.
  • Lookup order: L2 exact hit → L1 hit + view rebuild → full cold scan.

Cache commands

# Inspect cache state
$ sourcecode cache status
 
# Warm ahead of an agent session
$ sourcecode cache warm
 
# Clear cache for a repo
$ sourcecode cache clear --yes
 
# Force fresh scan (CI, verification)
$ sourcecode . --compact --no-cache

Cache stored at .sourcecode-cache/ inside each repo. Cache hits are silent — use cache status to inspect size, hit keys, and last-warmed timestamp.

what changes at 0.3s vs 2.7s

At 2.7s per call

You use sourcecode to occasionally inspect a repo. One call at session start, maybe once more mid-session. You batch calls and avoid redundant ones.

At 0.3s per call

You call sourcecode before every edit, every PR review, every test run. It becomes constant infrastructure inside agent loops — not a tool you batch around.

commands

Eight commands. Each answers a specific engineering question.

sourcecode impact

Blast-radius analysis [Pro]

Traverse the reverse dependency graph for any class. Returns direct callers, transitive callers, affected HTTP endpoints, transactional boundaries, cross-module impact, and a 0–100 risk score. Always target the interface in Spring Boot — not the implementation.

sourcecode onboard

Codebase orientation [Free]

Bounded AI-ready context bundle: entry points, architecture summary, key files, confidence level, and gaps. Designed for injection as agent system prompt at session start.

sourcecode endpoints

REST API surface

Extracts all Spring MVC and JAX-RS endpoint methods. Returns HTTP method, path, controller, and handler. Useful for auditing API surface before migrations or security reviews.

sourcecode review-pr

PR risk assessment [Pro]

Changed files, risk ranking, test coverage gaps, affected modules, and blast radius of changed classes. Returns a ci_decision field for CI/CD gates.

sourcecode fix-bug

Bug triage context [Pro]

Feed a symptom string, get a risk-ranked file list correlated by keyword extraction, path matching, content analysis, and git commit correlation. Full evidence chain in symptom_explain.

sourcecode modernize

Modernization planning [Pro]

Identifies high-coupling nodes (risky to change), dead zone candidates (safe to remove), and subsystem tangles. Quantified by fan-in degree across the symbol graph.

--compact / --agent

AI context modes

--compact gives a 2,500–4,000 token summary with transactional_boundaries for Spring. --agent adds file relevance and architecture detail at 4,500–5,500 tokens.

sourcecode repo-ir

Symbol-level IR

Deterministic symbol graph: classes, methods, import/injection edges, Spring roles, subsystems. Use --summary-only (~20K tokens) unless you need the full graph for downstream tooling.

sourcecode mcp

MCP server integration [Pro]

Run sourcecode as a live MCP server for Claude Desktop and Cursor. AI agents can query impact, endpoints, and context through the protocol — no manual CLI calls, no token-stuffing. sourcecode mcp init to set up.

design philosophy

Built on opinions. Held accountable to them.

determinism over approximation

Same repo, same output.

Every run on the same repository produces identical output. Agents, pipelines, and teams can cache it, diff it, and depend on it.

interface-aware traversal

Spring DI is not a black box.

The dependency graph understands interface injection patterns. Query OrderService (interface), not OrderServiceImpl. Real blast radius, not grep results.

bounded by default

Output fits in a context window.

Every AI-facing output mode (--compact, --agent, onboard) is size-bounded. No silent context window overflow.

local-first, privacy-respecting

No code leaves your machine.

No API keys required. No network requests. Fully offline. Analysis is entirely static and runs on your hardware.

composable, not monolithic

Output is infrastructure.

Pipe it, parse it with jq, inject it, gate on it. Structured JSON that works with any tool that reads stdin.

confidence-aware

Honest about what it doesn't know.

Every analysis includes a confidence summary and gap list. JAX-RS subresource patterns, SPI architectures, and programmatic security are flagged — not silently wrong.

privacy & telemetry

Transparent by default.

Telemetry is opt-in only and disabled by default. Only anonymous usage metadata is ever collected — never source code, paths, or output content. Runs fully offline.

data collection policy · v1.0
NEVER Source code contents, file bodies, or repository data
NEVER Credentials, API keys, tokens, or secrets
NEVER Repository names, paths, or directory structures
OPT-IN Anonymous usage metrics (invocation count, flags used, error types)
OPT-IN Aggregated performance telemetry (run duration, output size buckets)

why it's different

What nothing else gives you.

Spring DI-aware traversal

Real blast radius, not grep results.

Spring callers inject via @Autowired on the interface. Grep returns zero. sourcecode traverses the injection graph and returns the actual callers — 74 where grep finds none.

sub-second at 7,000+ files

Content-hash cache. Cold scan: 10.5s for Keycloak (7,885 Java files), 2.7s for BroadleafCommerce (2,985 files). Cache hit: 0.6s and 0.3s respectively. Safe to run in CI on every commit.

token-bounded output

Fits in any context window.

--compact is 2,500–4,000 tokens. --agent is 4,500–5,500. Deterministic — same repo, same output. Pipe directly to Claude or GPT-4 without overflow risk.

no cloud, no API key

Fully local. Source code never leaves.

pip install sourcecode and it works offline. No accounts, no usage limits, no network calls during analysis. Enterprise privacy requirements satisfied by default.

honest confidence signals

Every output says what it doesn't know.

Each analysis includes a confidence_summary and analysis_gaps list. JAX-RS patterns, SPI architectures, and programmatic security are flagged — not silently wrong.

evidence chain, not heuristics

Every file ranking shows its evidence.
